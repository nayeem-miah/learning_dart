# Module 1 — Dart Basics

This module introduces basic Dart syntax and variable usage.

## What is included

- `class1.dart` shows:
  - printing values with `print()`
  - Dart variable types: `String`, `int`, `bool`
  - `var`, `final`, `const`, and `dynamic`
  - string interpolation and concatenation
  - simple practice examples for user information, temperature conversion, and area calculations

- `class2.dart` shows:
  - control flow: `if`/`else`, `switch`
  - higher-order functions and closures
  - null-safety basics: nullable types (`?`), non-null assertion (`!`)
  - simple classes and constructors
  - small practice exercises: calculator, list filtering, and a basic class example

- `class3.dart` shows:
  - loops: `for`, `while`, `do`/`while`
  - functions, arrow functions, and returning values
  - list, map, and set usage
  - collection methods: `map`, `where`, `firstWhere`, `any`, `reduce`, `fold`
  - object-style maps and basic collection exercises

## How to run

1. Open a terminal in `module_1`
2. Run one of the examples:
   ```powershell
   dart run .\class1.dart
   dart run .\class2.dart
   dart run .\class3.dart
   ```

## Notes

- `const` values are compile-time constants and cannot change.
- `final` values cannot be reassigned, but can be set at runtime.
- `dynamic` variables can hold values of any type and can change type.
- Use `var` when the type can be inferred from the assigned value.
