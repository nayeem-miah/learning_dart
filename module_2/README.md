# Module 2: Dart Object-Oriented Programming

This module covers essential Object-Oriented Programming (OOP) concepts in Dart, including classes, constructors, inheritance, and advanced class features.

## Topics Covered

### 1. **Basic Classes**

- Creating classes with properties and methods
- Constructors and object instantiation
- Methods like `getInfo()` for returning formatted data

### 2. **Named Constructors**

- Creating multiple constructors with different names
- Example: `User.guest()` - creates a guest user with default values
- Useful for factory patterns and different initialization scenarios

### 3. **Getters and Setters**

- Using `get` keyword for computed properties
- Example: `get finalPrice` - automatically calculates final price with tax
- Encapsulating complex logic behind simple property access

### 4. **Private Properties**

- Using underscore `_` prefix to mark properties as private
- Example: `_balance` in `BankAccount` class
- Protecting internal state from direct access

### 5. **Inheritance**

- Extending classes using `extends` keyword
- Inheriting properties and methods from parent classes
- Example: `Dog extends Animal`

### 6. **Method Override**

- Overriding parent class methods in child classes
- Using `@override` annotation for clarity
- Polymorphism in action

### 7. **Required Named Parameters**

- Using `required` keyword in constructors
- Enforcing mandatory parameters
- Cleaner API design with named parameters

### 8. **Nullable Properties**

- Using `?` to make properties optional
- Handling null safety in Dart
- Creating flexible models with optional fields

### 9. **JSON Serialization**

- Creating `fromJson()` factory method
- Converting JSON objects to Dart model instances
- Essential for API and data handling
